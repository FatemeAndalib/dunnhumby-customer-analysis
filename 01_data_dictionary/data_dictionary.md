# Dunnhumby Customer Analytics

## 1. Project Overview

This project focuses on analyzing customer purchasing behavior using the Dunnhumby - The Complete Journey dataset.

The main objective is to explore transactional data, understand customer behavior, identify customer segments, and evaluate marketing campaign performance.

## 2. Dataset Information

- Dataset Name: The Complete Journey
- Data Provider: Dunnhumby
- Data Type: Retail and Customer Transaction Data
- Analysis Tools: SQL Server, Power BI
- Project Type: Customer Analytics and Business Intelligence

## 3. Project Objectives

- Analyze customer purchasing behavior.
- Identify key customer segments.
- Evaluate product and basket purchasing patterns.
- Analyze marketing campaign performance.
- Develop business insights and recommendations.
